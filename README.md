# Honeybee's BTO Journey 🐝

A personal planning dashboard for a Singapore HDB BTO application (Tampines, Feb 2027 launch): HFE letter steps, the 8-stage BTO guide, a financial planner, documents checklist, milestones and a knowledge centre.

Live site is served by GitHub Pages from `docs/`. Progress on the live site is saved in each browser (localStorage).

Figures marked "reported" come from news/property sites — always confirm on [HDB](https://www.hdb.gov.sg) and your own HFE letter. Not financial advice.
